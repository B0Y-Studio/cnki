# CNKI 知网文献爬虫

基于 Selenium 的知网文献自动爬取工具（Edge 浏览器）

## 功能

- 自动打开 Edge 浏览器进入知网高级检索页面
- 用户手动设置检索条件并通过验证码
- 自动翻页提取：**标题、作者、来源、发表时间、关键词、摘要、被引频次**
- 实时保存到 Excel，每页保存一次防止中断丢失

## 使用方法

```bash
# 安装依赖
pip install selenium webdriver-manager pandas openpyxl lxml

# 运行
python cnki_crawler.py
```

按提示操作：
1. 设置保存目录和最大下载篇数
2. Edge 浏览器自动打开知网高级检索页面
3. **手动输入检索条件 → 过滑块验证 → 点击检索**
4. 回到终端按 Enter
5. 脚本自动翻页爬取所有结果

## 爬取内容

| 字段 | 来源 |
|------|------|
| 标题 | 搜索结果页 |
| 作者 | 搜索结果页 |
| 来源期刊 | 搜索结果页 |
| 发表时间 | 搜索结果页 |
| 被引频次 | 搜索结果页 |
| 关键词 | 详情页 |
| 摘要 | 详情页 |

## 延时设置

- 每篇论文间隔：8 秒
- 翻页间隔：4 秒

## 环境要求

- Windows 系统
- Microsoft Edge 浏览器
- Python 3.7+
