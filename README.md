# CNKI 知网文献爬虫

基于 Selenium 的知网文献自动爬取工具（Edge 浏览器）。

**完全便携**：只需一个 `.py` 文件，首次运行自动创建虚拟环境并安装依赖。

## 功能

- 自动打开 Edge 浏览器进入知网高级检索页面
- 用户手动设置检索条件并通过滑块验证码
- 自动翻页提取：**标题、作者、来源、发表时间、关键词、摘要、被引频次**
- 实时保存到 Excel，每页保存一次防止中断丢失

## 使用方法

**只需要 Python 环境**，不需要手动安装任何包：

```bash
python cnki_crawler.py
```

首次运行会自动：
1. 创建 `venv/` 虚拟环境
2. 安装 selenium、pandas 等依赖
3. 打开 Edge 浏览器

之后按提示操作：
1. 设置保存目录和最大下载篇数
2. Edge 浏览器自动打开知网高级检索页面
3. **手动输入检索条件 → 过滑块验证 → 点击检索**
4. 回到终端按 Enter
5. 脚本自动翻页爬取所有结果

### 给朋友使用

直接把这个文件发给他们，运行 `python cnki_crawler.py` 即可，所有依赖会自动安装。

## 延时设置

- 每篇论文间隔：8 秒（避免触发反爬）
- 翻页间隔：4 秒

## 环境要求

- Windows 系统
- Microsoft Edge 浏览器（Windows 11 自带）
- Python 3.7+
